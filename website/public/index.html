02 Built for agents

It sees what it builds.

Language models are bad at picturing 3D, so ShapeItUp doesn't ask them to. After every change the agent gets pictures, measurements and plain-English errors back, and uses them to decide what to fix next.

  1. 01

    Write

    The agent writes TypeScript with create_shape and modify_shape. A bundled skill teaches it the Replicad API and the standard library, so it doesn't have to guess.

  2. 02

    Look

    render_preview returns one image with four views (top, front, right and iso), plus the bounding box, volume and mass. The agent checks the part from every side, not just the flattering one.

  3. 03

    Check

    verify_shape, check_collisions, validate_joints and sweep_check test that parts fit, joints line up, moving parts don't collide, and the model is printable.

  4. 04

    Fix

    Errors point to the line in the agent's own file and come with a suggested fix. So the next attempt starts from what actually went wrong.

03 Direct manipulation

04 Components & assemblies

One file, one part.
Import it anywhere.

standoff.shape.ts export function makeStandoff()
plate.shape.ts export function makePlate()
assembly.shape.ts import { makePlate } from "./plate.shape"

Every .shape.ts renders on its own. Import it into another file and it becomes part of an assembly. Change the component, and every assembly that uses it updates on the next render.

import { makePlate } from "./plate.shape";
import { makeStandoff } from "./standoff.shape";
import { patterns } from "shapeitup";

export default function main() {
  return [
    { shape: makePlate(100, 80, 4), name: "plate" },
    ...patterns.grid(2, 2, 58, 49).map(/* standoffs */),
  ];
}

06 Also in the box
Simulation

Watch it move before you print it.

Declare bodies, joints and motors in the file. Kinematic sweeps catch collisions, and Rapier or MuJoCo physics give you gravity, settling and pin forces.

Export

STEP, STL and 3MF.

One file, or one file per part. Send it straight to PrusaSlicer, Bambu Studio, OrcaSlicer, Cura or FreeCAD.

Printability

Checked for printing, not just for looks.

Overhang and thin-feature warnings for each part, print-orientation hints, and layoutOnBed to lay out a whole assembly on the print bed.

Headless

Runs in CI.

No GPU, no Chromium, no native graphics. The first render takes about 3 s while the kernel compiles, and later renders take under 200 ms. Works in Docker and GitHub Actions.

Parameters

Sliders come from the code.

export const params gives you a slider for each value. The agent can try different values with tune_params without editing the file.

Git

Your CAD is a diff.

Parts are plain text, so they work with branches, code review, blame and revert. A viewport edit shows up as one line in a commit.
